# chunkwork

A Minecraft mod and server manager cross-platform.

## Get started

To run in dev mode app for desktop:

```bash
bun run tauri dev
```

For web version:

```bash
bun run dev
```

For Android version:

```bash
bun run tauri android dev
```

## Technologies

### Frontend

Frontend uses Bun as the runtime and SvelteKit as the framework. The frontend is written in TypeScript.

### Backend

Rust.
